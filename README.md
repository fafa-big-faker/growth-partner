# 成长伙伴 · 社交成长任务系统

一个为帮助大学生建立社交能力而设计的游戏化成长任务系统。

## 功能

- **任务中心**：管理员发布/编辑/删除任务，用户领取/提交/放弃任务，支持自主申报
- **成长看板**：正向展示成长数据（等级、积分、雷达图、趋势图）
- **奖励中心**：管理员发放奖励，用户查看奖励记录
- **总结报告**：自动生成月度/学期/年度报告，支持导出
- **双角色系统**：管理员（哥哥）和用户（妹妹）权限隔离

## 设计原则

- 正向激励唯一：只有奖励，没有惩罚
- 基础生活费与任务完全脱钩
- 初始低分仅管理员可见，用户端只展示成长增量
- 清新温暖的视觉调性，非KPI/办公风格

## 技术栈

- 纯前端：HTML + CSS + JavaScript（无后端依赖）
- 数据存储：浏览器 localStorage
- 图表：原生 SVG 手绘
- 部署：静态文件，可直接托管在 GitHub Pages 等平台

## 使用方法

1. 用浏览器打开 `index.html`，或部署到任意静态服务器
2. 管理员密码：`admin`
3. 用户密码：`user`
