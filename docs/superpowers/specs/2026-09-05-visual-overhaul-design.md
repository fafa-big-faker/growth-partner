# 寻道大千美术升级设计

## 目标

在不改动玩法数值、数据库结构和页面信息架构的前提下，将玩家端从临时网页素材升级为统一的像素国风游戏界面。保留已经精修的道具和仙斧图标，补齐背景、仙树、功能图标、背包皮肤和砍树反馈，并修复十连砍动作之间穿插待机帧的问题。

## 美术方向

- 以现有道具图标为风格锚点：精细像素画、清晰深色轮廓、适量高光、较高辨识度。
- 主色使用玉绿、宣纸白和鎏金，辅以朱红、靛蓝、紫色和木色区分状态，避免整页只有单一色相。
- 所有生成素材不包含文字；名称、数量和按钮文字继续由网页渲染，保证清晰和可维护。
- 角色本轮保留现有序列帧；待机不连贯留到后续素材重制。已有道具图标不重新生成。

## 费用控制

最多进行四次 `gpt-image-2` 正式生成，不做额外付费草稿：

1. `scene-atlas`：四宫格场景背景，尺寸 2048x1152，中等质量。
2. `tree-atlas`：三阶段仙树横向图集，尺寸 1536x1024，中等质量。
3. `ui-atlas`：背包格、品质框、面板装饰和按钮底图，尺寸 1024x1024，中等质量。
4. `feature-effects-atlas`：功能图标、落叶和命中特效素材，尺寸 1024x1024，中等质量。

同类素材在一张规则网格内生成，再由确定性脚本统一裁切。若个别素材不理想，优先通过裁切、缩放、颜色和代码特效修正，不自动重复生成整张图集。

## 图集与页面映射

### 场景背景

四个 16:9 单元分别用于登录、修炼、任务和天道酬勤。背景只承担氛围，不承载文字或角色；移动端使用居中裁切，人物和交互控件仍由独立图层渲染。

### 仙树

生成幼苗、灵树和神树三档，对应现有 `tree-sprout`、`tree-spirit`、`tree-divine` 映射。每棵树独立居中、统一基线、纯色键控背景，裁切后转为透明 PNG。

### 界面皮肤

背包格和品质框作为重复单元使用；页面面板主体仍由 CSS 构建，只叠加轻量纹理和边角装饰，避免图片拉伸变形。五种品质继续沿用灰、蓝、紫、粉、金的游戏含义。

### 功能图标与特效

替换玩家端导航、邮件、成就、锻造等仍使用 emoji 的主要入口。落叶和命中火花只生成少量基础贴图，由程序随机控制位置、旋转、速度和透明度；树木震动沿用 CSS 动画。

## 动作衔接

单次砍树播放完整砍树序列后恢复待机。十连砍每次动作结束后停留在最后一帧，等待该次数据库结果；下一次直接从砍树第一帧开始，十次完成后才恢复待机，因此网络延迟不会暴露待机帧。

## 性能与兼容

- 背景输出 WebP，透明树木、UI 和特效输出 PNG/WebP，并保留源 PNG。
- 首屏素材预加载；非首屏背景按页面使用加载。
- 不修改背包格尺寸、玩法数据、Supabase 表和飞书配置。
- 同时检查 375x812 手机和 1440x900 桌面视口，无横向溢出、遮挡或文字图片化。

## 验收标准

- 玩家四个主页面具备统一背景和 UI 语言。
- 三档仙树均无底色方块、边缘明显色边或尺寸跳变。
- 背包图标清晰，数量角标始终可读，品质框易辨识。
- 点击砍树立即出现角色动作、树震、落叶与命中反馈。
- 十连砍的十次动作之间不出现待机帧。
- 相关自动测试通过，浏览器控制台没有新增错误，GitHub Pages 资源均返回成功。
