# 仙阶、仙树与锻造节奏优化设计

## 目标

- 同步飞书角色仙阶表最新的 `max_axe_quality`，让仙斧穿戴等级与配置一致。
- 精简仙斧穿戴要求，只保留“适配仙阶：{仙阶}及以上”，未达标时使用红色状态。
- 让仙树形象由 `tree_appearance` 配置决定，并让三种树形都对准角色砍击点。
- 将锻造最短演出时间随机控制在 2 至 3 秒，同时保留网络慢时的连续等待表现。

## 配置数据

角色仙阶表是仙斧穿戴限制的唯一数据源。最新配置对应关系为：凡品从小卡拉米、精品从小修士、珍品从小飞升、神品从小神、仙品从大罗金仙开始装备。

仙树灵阶表的 `tree_appearance` 是仙树外观的唯一数据源：灵阶 0 至 3 使用 `sprout`，4 至 10 使用 `spirit`，11 至 15 使用 `divine`。`game-config.js` 仍由 `sync-config.py` 生成，不手工修改。

角色仙阶表和仙树灵阶表都改为按第一行英文参数名读取，避免列位置变化导致错读。当前参数名保持飞书现状，包括角色表中的 `reqItems`。

## 仙斧穿戴信息

武器详情不再同时展示“可穿戴/尚未满足穿戴要求”和当前仙阶。身份区只展示品质，下面只保留一行穿戴要求：

`适配仙阶：小飞升及以上`

达到要求时使用克制的成功色和勾图标；未达到时文案完全相同，使用错误色和锁图标。禁用装备按钮仍可显示“仙阶不足”，因为它是操作结果而非重复说明。

锻造结果使用同一最低仙阶计算逻辑。无法装备时显示同样的红色要求，并以次要文案说明仙斧已经放入背包。

## 仙树外观与场景锚点

建立受控的仙树外观注册表。每个外观包含运行资源地址和自身的布局参数，配置只选择 `sprout`、`spirit` 或 `divine`；未知值回退到 `sprout`，不能产生无效资源路径。

场景使用统一的地面基线和砍击锚点。三种素材分别调整显示尺寸与水平/垂直偏移，使树干受击位置与角色斧刃落点重合。人物层级高于树，命中和落叶特效层级高于人物。移动端使用独立的响应式参数，但保持相同的锚点关系。

仙树详情与修仙场景都从当前 `treeRealm` 的 `appearance` 获取同一张图，删除按等级阈值写死的 `getTreeImage()` 分支。

## 锻造时间轴

每次开始锻造时抽取一个 2000 至 3000 毫秒的最短演出时长。锻造揭晓必须同时满足两个条件：最短演出时间结束，并且真实数据库结果已经返回。

候选仙斧先按现有序列加速，随后以高速率持续轮播。进度条在最短演出时间内平滑推进至 98%；若网络仍未返回，就停在 98% 但继续轮播。真实结果返回后停止轮播、补满 100% 并揭晓。网络错误继续交给现有锁定操作处理，不能提前显示成功。

减少动态效果模式不轮播候选图片，但仍显示状态与连续进度，并遵守相同的最短演出时间。

## 验证

- 配置测试覆盖英文表头、最新仙阶上限和 `tree_appearance` 输出。
- 武器详情测试覆盖精简文案、达标与未达标状态及锻造结果一致性。
- 场景测试覆盖配置外观选择、未知值回退、三种布局类和层级。
- 锻造测试覆盖 2 至 3 秒最短时长、同时等待时间与结果、98% 等待状态和错误传递。
- 发布前运行完整 JavaScript、Python、图片资源和语法测试；不修改玩家数据，不执行额外浏览器视觉验收。
