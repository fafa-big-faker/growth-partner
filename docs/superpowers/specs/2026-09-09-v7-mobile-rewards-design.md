# V7 奖励与手机双栏设计

用户已确认布局和交互，并提供美术风格参考V7，授权直接实现发布。本说明不新增待确认设计。

## 奖励展示

- 按 `isExtra` 区分普通和额外奖励，不依赖数组第十一项。十连普通奖励保持5+5，额外奖励另行居中。
- 单次、十次与额外奖励共用品质墨团及图标排布，数量、技能效果和返还次数保留。品质色标题在纸面上清晰可读。
- 只改表现，不改变奖励包、抽取、消耗或发放。
- 普通物品详情名字按自身品质着色；武器保留技能重点布局。

## 手机布局

- 顶栏、砍树场景与紧凑状态、常展开双栏背包、统一底部操作导航。
- 背包左侧约3/5是普通道具，右侧约2/5是当前装备和技能。整体只使用一张新纸面，不嵌套背景框。
- 右侧底部“武器库”切换右侧为两列独立武器实例，包含标记“当前”的已装备实例。按钮同时变成“返回”，不要求换装即可返回。
- 点击武器打开详情，装备必须明确点击装备。当前装备不得出售。换装与开详情保留两栏滚动和右侧模式。
- 底部任务在左、砍树在中、天道酬勤在右，十连和锻造分别位于侧上方。任务/商店中间改成返回修仙，隐藏次数、十连及锻造。
- 手机仍只使用唯一 `inventory-grid` 和现有游戏状态；不复制玩家数据。电脑版保留原布局与页签。
- 短屏整体缩放树和角色所在场景层，保持既有锚点、命中区域、十连节奏与数量角标。

## 验证与边界

- 不改配置、数据库和测试账号数据，不进行浏览器截图视觉验收。
- 运行模拟数据的多视口几何、交互、滚动保留及图片解码检查；全套回归和静态检查通过后发布。
- 新图片按真实alpha裁切，源图不覆盖，运行WebP与源指纹可重建。
