# 砍树操作区美术与交互优化设计

## 目标

让砍树成为修仙页最明确、最有质感的核心操作，同时简化锻造入口，并在仙树满足升阶条件时提供克制但清楚的提醒。

## 已确认方案

- 砍树按钮使用新水墨圆形背景，桌面端约 118px，窄屏等比收缩。
- 当前装备斧头在圆形按钮内放大，允许斧刃越出水墨边界，保持完整轮廓和清晰阴影。
- 砍树次数移到按钮底部，只显示数字，不添加“余”等说明文字。
- 悬浮时斧头围绕握柄轻晃两次；点击时斧头短促下劈、按钮轻微收缩，并扩散一圈淡墨波纹。
- 禁用态保持可辨认，但降低饱和度、对比度和动画，避免误导为可操作。
- 装备信息栏右侧仅展示新锻造图标，不展示锻造石数量；图标适度越出信息栏边界，悬浮与点击均有轻量反馈。
- 当存在下一仙树灵阶且全部升阶材料足够时，在树冠附近显示低透明青绿色“可升级”提示，缓慢上下呼吸；任一条件不满足或达到满阶时隐藏。

## 数据与边界

- 不修改飞书配置、Supabase 结构或玩家数据。
- 升阶提示复用同一套纯判定函数，避免主页、详情弹窗与升阶弹窗条件不一致。
- 新资源纳入现有 `assets/images/v2` 源图与 `assets/runtime/v2` WebP 构建流程，并加入登录预加载。
- 保留十连砍布局和原有砍树/锻造业务逻辑，仅调整表现与入口内容。

## 验证

- 自动测试覆盖升阶条件、DOM 结构、纯数字次数、锻造石信息移除、动画与资源引用。
- 运行完整 JavaScript、Python、图片规格、语法和差异检查。
- 按用户约定，本次不做浏览器视觉验收。
