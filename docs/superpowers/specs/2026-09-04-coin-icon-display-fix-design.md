# 游戏币图标显示修复设计

## 目标

修复两处仍使用系统表情显示游戏币的界面，使其统一显示道具 ID `0` 对应的本地图片图标：

- 天道酬勤商店标题右侧的当前游戏币余额。
- 武器详情弹窗中出售按钮的售价。

## 实现

复用现有的 `renderItemIcon` 函数，不新增图标路径或独立组件：

- 商店余额使用 ID `0` 和 `res-coin-img` 尺寸类。
- 出售按钮使用 ID `0` 和 `item-icon-xs` 尺寸类。
- 武器可装备和仙阶不足两条按钮渲染分支使用相同的售价结构。

不修改飞书配置、Supabase 数据、出售逻辑或商品价格逻辑。

## 验证

- 本地打开天道酬勤页面，余额前显示游戏币图片且数字不移位。
- 打开一件可出售武器的详情，按钮内显示游戏币图片和正确售价。
- 检查窄屏下按钮内容不溢出，图片加载成功，浏览器控制台无相关错误。

## 回退

改动仅涉及前端模板和必要的局部样式，可通过对应 Git 提交完整回退。
