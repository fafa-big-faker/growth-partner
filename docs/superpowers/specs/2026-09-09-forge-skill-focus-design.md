# 仙斧技能优先展示与评级

## 已确认的设计

以用户补充的锻造原型图为顺序依据：紧凑斧头框（框内装备操作）、斧头名称、品质、技能正文、装备文案、材料数量、再次锻造、折叠概率。

- 斧头框缩为144x174px，短屏128x154px；框内操作始终44px，不随结果出现而撑高。
- 同一信息区在准备/锻造时显示状态和进度，结果时隐藏它们并显示品质、技能和文案。技能正文用深墨色，动态参数仍使用既有BUFF/目标品质颜色。
- 信息区固定160px，长技能及文案可内部滚动。弹窗内容区可在短横屏滚动；底部材料和再次锻造不被推走。无技能明确显示“暂无斧技”。
- 保留2至3秒随机时间轴、前60%推进至98%、后40%高速轮播及后台等待、防连点、UUID装备和材料实时刷新。
- 用户已确认：技能品质1至5对应B/A/S/SS/SSS，多技能取最高有效品质，无技能为B。只读取实例保存的skillRolls，不按道具品质或配置重新计算词条。

## 美术依赖与交付边界

五枚评级字标必须为正式AI图集，不用CSS徽章或临时字标冒充完成。本会话无内置生图工具；未经明确确认不切换付费API。交付单图提示词，图片到位后裁切接入背包格底部。当前版本先交付锻造布局与独立可测的评级函数，尚不启用背包评级显示。

正式图片目标为1536x1024透明PNG，3列2行，B/A/S、SS/SSS/空；字高与基线一致。格底18px留给评级，当前状态移至右上辅助状态区，格子尺寸、武器UUID及两栏滚动不变。

## 验证

- 单元测试：1至5映射、双技能顺序、无技能和坏数据、同道具不同实例、读取不修改。
- 模拟浏览器：手机/电脑/横屏的准备、锻造、成功、装备、再锻造、失败和双技能；进度仅在抽取时可见，技能在主按钮之前，重复锻造位置稳定，概率展开可滚动。
- 全套原有Node/Python、语法、资源和无截图浏览器回归；不操作真实玩家。
- Git仅提交本需求文件，不纳入已有supabase/。发布需确认Pages成功及线上文件匹配。
