# 演示十连砍突破弱引导

用户已确认并要求执行。这里只记录已确认的范围，不需要再次确认。

- 仅演示修炼者在尝试开启十连砍且仙阶不足时出现；复选框恢复关闭。
- 突破按钮上方以浅纸色小提示配墨绿向下箭头，轻微浮动。文案“突破至中卡拉米，解锁十连砍”。
- 无遮罩、不锁屏、不改变焦点、不阻止原操作；下一次点击任意位置即消失。点击突破同时打开原突破弹窗，不增加点击次数。
- 触发提示的那次点击不算关闭；重复尝试可再次提示，始终仅一个提示。
- 演示提示成功显示时替代原解锁气泡，找不到可见目标时退回原气泡。正式账号仍保持原气泡。
- 不足十次、关闭勾选、已达到仙阶不会触发。切页、重新渲染、退出登录、目标失效时清理。
- 不与砍树/赠送武器/锻造强引导、其他弹窗叠加；手机及桌面均按真实突破按钮定位，提示不溢出屏幕。
- 不保存引导状态、不改玩家数据、不改解锁要求，不新增美术资源。

验证：真实复选框/标签点击、触屏与键盘、直接点击突破、重复点击、切页/退出、各种未触发分支，以及现有演示完整玩法链路。
