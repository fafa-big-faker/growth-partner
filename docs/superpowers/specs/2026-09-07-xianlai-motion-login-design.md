# 仙来美术准备、登录和动作稳定性

## 已授权范围与顺序

用户要求先提供带尺寸、比例的美术提示词和可选动效示意，再处理十连砍和待机对齐；不重复征求执行确认。美术原图由用户生成，本次不调用付费生图、不替换正式登录背景。

1. 资源目录的 `仙来-美术生成提示词.md` 提供四次生成：2048x1536 登录背景、1024x512 独立仙来 logo、2048x1536 六格框图集、1536x1024 六格功能图标。
2. 水墨演示只呈现一次 logo 揭示、轻缓边缘运动和加载反馈。复用现有位图，书法字暂作占位，不冒充正式美术。
3. 十连砍按钮在每个角色动作开始时播放下劈，使用同一个 1x 到 3x 的速度值；不能多调用砍树接口，不能增加第十一次表现。清理旧动画定时器，避免截断下一次。
4. 登录采用浏览器原生密码管理器、真实表单和角色用户名。修炼者与天道隔离，仅成功登录后建议保存，不自动登录，不把密码写入 localStorage、IndexedDB、文件或日志。不支持凭据 API 时仍可普通登录与原生表单自动填充。
5. 待机帧保留每把武器第 1 帧和所有砍树帧，以身体/脚部局部特征对齐第 2 到 4 帧。不能按斧头与裙摆全图包围盒重新居中，不裁掉有效像素；输出可重复构建的校正记录。

## 验证与发布

分别验证十次事件节奏、动画清理、密码 API 拒绝/不支持/角色错配、36 帧尺寸透明度及内容完整性。运行完整 Node 测试、语法检查、图片测试和 diff 检查。用户不要求全局浏览器视觉验收；只验证本次明确要求的演示。保留并排除未跟踪的 supabase/，不操作用户数据。测试通过后按现有流程推送 main。
