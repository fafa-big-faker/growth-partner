# Xianlai V4 Implementation Plan

> **For agentic workers:** Use the available executing-plans workflow with bounded parallel workers; the specialized subagent-driven-development skill is not installed. Each worker owns the files/functions listed below.

**Goal:** Integrate the approved V4 art and names, simplify breakthrough presentation and make mobile chopping usable without scrolling away from its scene.

**Architecture:** Retain the vanilla application and its existing action/data ownership. Add deterministic V4 import/runtime assets, a centralized item-art resolver, isolated V4 surface CSS, and a mobile cultivation controller that moves the same inventory surface between its desktop host and a mobile drawer.

**Tech Stack:** Vanilla JavaScript/CSS/HTML, Node test runner, Python Pillow, existing Feishu CLI sync, GitHub Pages.

## Global Constraints

- No browser screenshots, no real-account test mutations, no Supabase edits, no generated configuration hand edits.
- Keep all IDs, recipe values, rewards, weapon skills, timelines and character anchors unchanged.
- Preserve unrelated user files and untracked `supabase/`.
- Stop and report if a single blocked step makes no progress for ten minutes.
