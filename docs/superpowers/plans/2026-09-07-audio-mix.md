# Audio Mix Correction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every short game sound clearly audible above the BGM and move mute controls into the top utility areas.

**Architecture:** A deterministic Node script reads the untouched WAV sources from `../音频资源`, peak-normalizes each category, and writes runtime copies. `audio-manager.js` then applies category mix volumes; player and admin markup place the existing shared control in their top utility areas.

**Tech Stack:** Node.js PCM buffer processing, browser `HTMLAudioElement`, vanilla HTML/CSS/JavaScript, Node.js test runner.

## Global Constraints

- BGM volume remains `0.18`.
- Every generated WAV remains 16-bit PCM and must not clip.
- The player mute control is beside mail and achievements, not floating above bottom navigation.
- Audio failure must not block login or gameplay.
- No browser visual acceptance unless explicitly requested.
