# 演示入口体验收尾（已获用户批准）

## 设计与边界

- 仅 `?demo=1`：隐藏整个身份选择行，保留居中的密码与登录入口。
- 加载页主文案固定为“首次需缓存资源，加载稍慢，请稍候。”，次级提示“演示进度不保存，重新登录即重置。”；正常入口保留轮播短句，真实进度和错误重试不变。
- 使用本次登录赠送的 SSS 武器实例成功单砍或十连砍，在结果关闭后等待约 300ms，引导点击真实天工开物入口。
- 标题“去天工开物，试试手气！”，正文“用开工石锻造仙斧，寻找更强的斧技。”；打开锻造界面即结束，不强制抽取。
- 本轮已成功锻造则跳过。失败的砍树/锻造、同名但不同实例的斧头不误触发；重新登录重置，切页/退出/新砍树取消过期引导。
- 沿用现有浮动气泡与遮罩，不制作美术、不进行截图视觉验收、不修改数据库或正式账号。

## 实施顺序

1. 为演示会话资格、引导时序/取消、加载文案补回归测试。
2. 收紧演示登录布局，简化加载提示；新增可取消的锻造引导，接入成功砍树后的结果关闭回调。
3. 更新功能浏览器测试：三种屏幕、单/十连砍、提前锻造跳过、重新登录、零数据库请求。
4. 更新文档与资源版本；执行完整测试、语法检查、资源校验和差异审查。
5. 推送 main，确认 Pages 部署及线上文件一致；原二维码和密码不变。
