# 仙来：仙斧评级字标

建议保存名：`仙来-仙斧评级字标图集.png`。一张图包含五款，放回项目资源目录后再统一裁切。不需要分开生成五次。

## 可直接用于生成的提示词

生成一张用于清新水墨像素修仙游戏《仙来》的仙斧评级字标图集。只生成美术字标，不生成游戏界面，不画武器、不画背包格子。

画布1536×1024像素，比例3:2，真正透明PNG背景，不要把灰白棋盘格画进图片。严格3列2行，每格512×512像素，不画格线。顺序固定：第一行“B”“A”“S”，第二行“SS”“SSS”，最后一格完全留空。五个评级分别只出现一次，没有标题、说明文字、数字、署名或水印。

字形是粗壮清晰、稍有书法笔势的英文大写字标，轻微像素化边缘，整体克制利落。像用饱满的彩墨写在纸上的短字，有少许干笔质感，但主笔画连续结实，不要大量飞白裂纹。SS和SSS的每个S必须清楚分开，不能连接成装饰花纹。

五款字高一致，字母本体高约160像素，笔画粗细一致，主笔画至少24像素；每个字标位于各自格子的正中央，基线一致。每个S约112像素宽，相邻字母间隔约12像素，SSS总宽不超过360像素。B、A和单S保持自然单字宽度，不要拉宽到SSS的宽度。每格所有笔锋和装饰限制在中央384×192像素安全区内，四周充分留白，方便后续裁切。

颜色由低到高依次：B为沉稳墨灰（#5C6660），A为青蓝（#3F79A4），S为雅紫（#8650A4），SS为玫朱红（#B04E69），SSS为深琥珀金（#B88A2E）。在浅色宣纸背景上仍要看得清。高评级可以更饱满、更有笔锋力量，但五款属于同一种平面彩墨材质，不要突然变成金属。只允许极细的深墨边缘增强清晰度，不要厚黑卡通描边。

优先保证缩小到36×18像素时仍能马上辨认B/A/S/SS/SSS。不要立体浮雕、金属反光、宝石、翅膀、皇冠、勋章底座、大墨团底板、光环、外发光、长拖尾或大颗粒特效。需要的是轻巧有进阶感的纯字标，不是老式MMO徽章。

## 接入约定

- 技能品质1/2/3/4/5分别对应B/A/S/SS/SSS，多个技能取最高，无技能为B。
- 图标目标裁切画布384×192，再输出192×96透明WebP；实际边界以生成图片测量为准，不盲目硬切。
- 手机武器格底部显示约36×18像素，电脑约44×22像素，不扩大格子，不遮斧头主体。
