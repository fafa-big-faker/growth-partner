# 首次砍树引导方案（待确认，尚未实现）

日期：2026-09-10。本次发布仅包含正式图标和仙树高清资源；本文记录用户两张原型所表达的首次引导，不代表功能已上线。

## 体验

两张原型理解为同一个强制操作的两个视觉阶段，不额外增加第二项教学任务。

1. 玩家首次成功登录，角色数据、场景资源和布局全部就绪后，约300ms淡入半透明黑色遮罩。保留砍树按钮及略超出圆底的斧头完整可见，让视线先落到操作位置。
2. 随后在按钮上方浮出小纸签气泡：“点一下仙斧，开始砍树”，辅助文案“每次砍树都能获得奖励”。聚焦圈做一次克制的收拢动作，之后维持轻微呼吸；复用现有纸面，不需要用户另生成素材。
3. 遮罩期间只允许点击真实砍树按钮；其余页面、遮罩空白处、滚动和安卓返回键均不能绕过。保留键盘操作和清晰焦点，减少动态设置下直接呈现稳定高亮。
4. 点击后立即淡出提示及遮罩，沿用现有单砍、按钮反馈、角色动作和到账结果。一次点击只消耗一次，不启动十连。网络请求期间沿用现有操作锁，避免连点；失败后恢复引导并允许重试。

## 完成与重复登录

- 只针对玩家角色，不在天道端或专用测试账号强制出现。
- 建议用玩家云端已保存的累计砍树次数`total_chops`识别：成功砍过至少一次即已完成，已有进度的玩家跳过。不以某台手机的本地标记作为唯一依据，因此正常换设备或重装不重复引导，也不需要新增数据库字段。
- 本次操作只有在实际成功后才视为完成。登录失败、资源失败或砍树失败都不能把引导标记为完成。
- 从未砍过树但已使用过其他功能的正式玩家也会看到一次，这是复用累计次数的明确边界。若以后扩展多步骤教程，再独立增加版本化的云端引导进度。

## 实现时的检查点

- 以真实砍树按钮的实时位置开聚焦孔，不复制一个假按钮；横竖屏、全屏和窗口大小变化时重新计算。
- 通过现有单次砍树入口提交，不在引导模块自行发奖励；必须保持`OperationGuard`和失败回退。
- 离页、退出账号、后台切换时清理或暂停引导；重新显示时检查账号与当前进度，避免旧账号的遮罩影响新账号。
- 聚焦孔边界包含斧头出头部分；气泡不盖住次数、按钮或超出短屏。遮罩关闭后恢复页面正常点击、滚动与焦点。
- 功能验证覆盖新玩家、已有进度、天道/测试账号、请求失败、重复点击及返回键。未经用户另外要求，不做浏览器视觉验收。
