## 如何体验

1. 扫码，完成资源准备后，在登录页输入888。首次需缓存资源，加载稍慢；加载页会显示真实进度和重置说明，演示登录不再显示身份选项。
2. 按首次引导砍树。角色10级、小卡拉米，已有三种突破材料各1个，可以点击突破。
3. 突破至中卡拉米后勾选十连砍，砍完收下奖励。
4. 若尚未装备赠送的SSS光头强淘汰斧，将出现换装引导：武器库 → 这把斧头 → 装备。

6. 继续体验斧技与锻造；任务提交后可点“模拟通过”，再领取奖励。模拟审核明确标注，不会发给真实天道。
