# Android 轻量版实现约定（2026-09-09）

用户已批准在线更新的轻量 Android 包装，当前实现沿用该范围。已排除重写原生游戏和离线复制数据库；它们会改变玩法与更新成本。采用无第三方运行框架的系统 WebView，最低 Android 8.0、目标 Android 15，名称仙来，固定包名 cn.xianlai.game。

工作拆为三个可独立验证的单元：导航策略负责可信站点边界；Activity 负责启动、失败重试、系统返回与前后台；本机构建脚本负责资源、编译、正式签名、校验和交付。网页通过既定 XianlaiShell 两个方法响应返回与生命周期，原生不向网页开放任何能力对象。图标复用正式修炼功能图，不生成新的美术主体。

实现计划：

- [x] 实现严格 HTTPS 主机及路径判断，并用真实 URI 边界样例运行 JVM 测试。
- [x] 实现 Activity、启动资源和系统 Insets；主文档失败留在可重试界面，TLS 始终拒绝，返回先委托网页。
- [x] 用现有 Unity Android SDK 编译，导出自适应图标；长期签名材料存仓库外并创建本地恢复副本。
- [x] 对齐、正式签名、验签、检查包名/版本/权限并记录 SHA256；交付同级安卓安装包目录。
- [x] 审查本次文件与密钥隔离，向父任务报告已测试和未测试范围；不自行提交或推送。

实际验证：27 个导航边界断言通过；Java/DEX/资源编译通过；同一长期证书二次构建通过；APK v2/v3 验签、对齐、包名及仅 INTERNET 权限通过。当前 APK 86,484 字节。图标导出及脚本语法检查通过。签名材料、APK、临时构建和 Python 字节码均不进入源代码提交。当前无连接设备与模拟器系统镜像，未执行 Android 运行验收。
